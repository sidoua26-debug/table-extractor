Got Questions?

Frequently Asked Questions

Does Table Extractor send my data to external servers?

No. Table Extractor runs 100% locally inside your browser sandbox. Your web page data is never transmitted across the network or stored on any server.

Can it handle virtualized or infinite scroll tables?

Yes! Many modern enterprise web applications (like AG Grid, Salesforce, or Airtable) use DOM virtualization where only visible rows exist in the HTML. Table Extractor automatically scrolls the container, stitches batches, and reconstructs the full dataset.

What formats are supported for export?

You can export directly to CSV (.csv), Microsoft Excel (.xlsx), structured JSON (.json), or copy clean Tab-Separated Values (TSV) directly to your clipboard.

Does Table Extractor run on background pages automatically?

No. Following the least-privilege security model, Table Extractor only injects into a tab when you explicitly open the extension popup. It does not monitor or track background tabs.
