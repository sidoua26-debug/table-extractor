## Audio & Music Specifications
- **Music Track**: Ambient tech lo-fi / upbeat corporate minimalism (starts at 30% volume, ducks to 15% under voiceover, rises to 25% on final outro chord).
- **Sound Effects (SFX)**:
  - `00:05`: Subtle soft error chime on messy sheet paste.
  - `00:10`: Clean digital mouse click on toolbar extension icon.
  - `00:12`: Gentle interface whoosh when table highlights on page.
  - `00:31`: Satisfying crisp "pop" / register click when Export button is tapped.
  - `00:34`: Crisp spreadsheet open chime.
- **Voiceover Delivery**: Professional, friendly, modern software product specialist tone. Moderate tempo (~135 words per minute), clear articulation.

## Recording Checklist for Creator
1. [ ] Set Chrome display scaling to 100% or 125% for crisp UI rendering.
2. [ ] Hide bookmarks bar and close unrelated browser tabs.
3. [ ] Pre-load target demonstration URL (e.g. `https://www.ag-grid.com/example/` or clean analytics dashboard).
4. [ ] Pin Table Extractor to Chrome toolbar.
5. [ ] Perform one dry run to ensure popup opens instantly and table detection highlights smoothly.
6. [ ] Have Microsoft Excel or Google Sheets ready in the background to open the downloaded CSV immediately.
